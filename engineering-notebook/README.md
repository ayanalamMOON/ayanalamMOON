# Engineering Notebook

This directory separates activity records from experimental conclusions.

- [Recent activity index](./RECENT_ACTIVITY.md) is generated from commits on the configured projects' default branches.
- [Experiment template](./EXPERIMENT_TEMPLATE.md) is for reproducible, human-authored investigations.

The generated activity feed is evidence of repository changes, not automatically fabricated research. Benchmark outcomes, accuracy claims, and performance conclusions belong in an experiment note only after they have been measured and documented.
